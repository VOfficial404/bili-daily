部署

四行命令，就能开始。

终端
mkdir -p /opt/bili-daily && cd /opt/bili-daily
curl -fsSLO https://raw.githubusercontent.com/VOfficial404/bili-daily/main/compose.yaml
docker compose up -d
docker compose exec bili-daily bili-daily token
  1. 跑这四行一台装了 Docker 的 Linux 服务器就够。最后一行输出的是登录用的令牌。
  2. 打开面板浏览器访问 http://127.0.0.1:8686，粘贴令牌登录。
  3. 扫码添加账号添加后马上跑第一轮，以后每天北京时间 09:30 起自己跑。

服务端默认只听本机。要从别的设备访问，用 SSH 隧道或 HTTPS 反向代理，别把明文端口开到公网。不用 Docker 的装法在 README 里。

下载

挑你的设备。

都在 GitHub Releases 的最新版本里。

Windows

bili-daily-desktop-setup-*-amd64.exe

安装包。不想装就下 *-portable.zip，解压就能用。

macOS

bili-daily-desktop-*.dmg

Intel 与 Apple 芯片通用。第一次打开时，在 Finder 里右键，选「打开」。

Linux

*.deb

Debian 与 Ubuntu 用它；其他发行版下 .tar.gz，解压后运行 install.sh。

Android

bili-daily-*-android-arm64.apk

Android 9 及以上。

iPhone

bili-daily-*-ios-unsigned.ipa

没有签名，用 AltStore 或 SideStore 自己签名安装。iOS 15 及以上。

服务器

ghcr.io/vofficial404/bili-daily

推荐用 Docker。也可以下 bili-daily_linux_amd64 这类单个文件，直接运行。

安装包没有代码签名：Windows 弹出 SmartScreen 时，点「更多信息」再选「仍要运行」。每个版本都附带 checksums.txt，可以校验文件。
